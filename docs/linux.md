# Linux build and compatibility notes

The Linux frontend uses GTK 3's C ABI, dynamically loading `libgtk-3.so.0` and resolving the required symbols at startup. This allows core tests and builds without GTK development files, but a GTK 3 runtime and a usable display are required to run the GUI. Missing GTK or display produces a diagnostic and a nonzero exit. `xdg-open` is used to open files. There is no daemon.

See the README for installation, build, cross-architecture and packaging commands. Releases distribute an installable `.deb`, not a portable archive; the package is not statically linked and the target still needs compatible libc, GTK 3, desktop integration and their transitive dependencies. Build and test on the oldest supported system to avoid inadvertently requiring newer glibc symbols. No claim is made that a binary built on Debian 12 runs on Mint 19.

The application creates a worker for each requested directory read. A generation counter discards stale results and stops iteration between entries, but cannot cancel a blocked kernel call. Rows are added 64 at a time to keep the main loop responsive; they are not virtualized, and reads, metadata and sorting can still be costly for large or remote directories. No profiling, GUI responsiveness, network drive or external drive testing has been performed yet.

File operations are deliberately limited: no-overwrite rename/move require Linux `renameat2` support, clipboard copy supports multiple regular files or bounded directory trees, and cut/paste supports bounded same-filesystem batch moves; duplicate supports one item without links or special files, and deletion requires confirmation and handles only individual files, symlinks, or empty directories. Copy stages in the target directory and checks paths without no-follow directory handles, so neither source nor destination should be concurrently writable by untrusted users. See the README for the full limitations. GUI actions have not been interactively tested.

Trash delegates to GIO and never falls back to permanent deletion. It supports up to 1,024 non-overlapping selected items, stopping at the first error or cancellation with earlier items retained in trash. A failed item can be partially processed; there is no rollback. Cancellation is checked between items. Archive extraction supports uncompressed TAR and, with a compatible system libarchive runtime, ZIP, 7z and gzip/bzip2/xz-compressed TAR on Linux x86/x86_64/aarch64. It rejects links and unsafe paths, uses no-follow directory-relative file operations, and applies resource limits. See the README for the exact supported TAR subset, partial-output semantics, and untrusted-directory restrictions.

ZIP, 7z and compressed TAR reading and extraction dynamically load `libarchive.so.13`; missing libraries or unsupported codecs produce an error. Linux tabs, clipboard, converters and archive GTK controls need further interactive testing; the GTK smoke test covers only a subset of actions. The converter additionally supports UTF-8 text to escaped HTML and restricted opaque 24-bit BMP/ICO conversion; see the [conversion matrix](development-plan.md).

For automated rustup installation and native/cross-builds, use `./scripts/build-linux.sh`; see the README for options, dependencies, output locations and compatibility limits. System package installation is opt-in.

## Debian package

The release workflow builds an architecture-specific `.deb` from its Ubuntu 18.04-based executable. The package provides an applications-menu entry, declares the runtime dependencies and is removable through the system package manager. Its install, launch and removal are tested inside the build container before publication. These packages have not yet run through the workflow or been tested on Mint 19 itself; v0.0.2 only contains portable downloads, which are no longer produced.

## Preview and removal UI

Right-click one file for the read-only built-in preview; see the README for supported extensions, size limits, decoding and security limitations. Other formats require an external application. Organize → Uninstall ZFM prompts before querying the Debian package database and running `/usr/bin/pkexec /usr/bin/dpkg --remove zfm`. PolicyKit authentication and dpkg dependency checks apply; no manual deletion is attempted for non-package installations. If authentication or removal fails, use the system package manager or `sudo apt remove zfm`. This UI has not yet been tested on Mint 19.

## Settings storage

Apply in the Settings window stores hidden-file visibility and sort direction in `$XDG_CONFIG_HOME/zfm/settings.conf`; if `XDG_CONFIG_HOME` is absent or not absolute, `$HOME/.config/zfm/settings.conf` is used. Changes through other controls are session-only until applied in Settings. Uninstall preserves this user file. A malformed or unrecognized settings file is not overwritten; correct or remove it manually to save new settings. Concurrent instances may overwrite each other, and parent paths are not protected against hostile concurrent changes.

7z archive inspection, testing and selected-entry extraction use system libarchive. The Linux archive manager also offers engine list, test and extract-all controls using the bundled 7-Zip engine, including separate password-protected actions. Extract-all does not support entry selection, is limited to 1,024 entries and leaves earlier outputs on failure. Compressed TAR is first expanded to temporary storage with a 1,088 MiB limit; crashes or failed cleanup can leave this temporary file behind. Archive creation uses the bundled engine: select one or more regular files or folders and right-click and choose a format under **Compress to**, or **Create encrypted archive…**. Creation supports 7z, ZIP, TAR, gzip/bzip2/xz-compressed TAR and aliases such as .tgz, and single-file .gz, .bz2 and .xz compression. Engine extract-all also expands these standalone streams, naming the output after the compressed input without its suffix; it requires hard-link support and caps expanded size at 512 MiB. Compressed TAR requires additional temporary disk space. Encrypted 7z and ZIP creation are supported; ZIP passwords are ASCII-only and ZIP filenames remain visible. Passwords are passed to the engine through stdin, but remain in memory and are not guaranteed to be erased. See the README for limits, staging and trust requirements. The engine is not sandboxed; avoid untrusted archives. Right-click one supported archive for **Extract here…**, **Extract to folder…**, or **Extract with password…**. The destination must already exist; earlier outputs remain on error or cancellation. These new controls have not been tested interactively.

Use **Copy to…** on selected files and folders to choose a destination, or **Move to…** for up to 1,024 items on the same filesystem. Batch moves stop on the first error or cancellation and do not roll back earlier moves; the status reports the completed count and failed item. **Organize** also opens the Converter and Archive manager and offers cancellation for supported operations. Earlier copied, moved or extracted outputs can remain after cancellation.

Use Ctrl+B to bookmark the current folder, or open **Bookmarks** in the sidebar to add, open, or remove folders. Bookmarks are stored in `$XDG_CONFIG_HOME/zfm/bookmarks.conf` (or `$HOME/.config/zfm/bookmarks.conf`) and remain after uninstall. They require absolute UTF-8 paths without control characters and are limited to 64 entries.

Enter a filename term and use Ctrl+Shift+F or **Organize → Search subfolders** for bounded recursive search. Results show relative paths; right-click to open the containing folder. The Case and Hidden options apply. Clear exits search mode. See the README for limits and filesystem caveats.

The offline converter supports uncompressed PCM WAV ↔ AIFF and WAV ↔ AU (8/16-bit mono/stereo only); metadata is not preserved. See the README for sample-rate, input-size, cancellation and safety limits.

F2 or Rename on 2–100 selected regular files in the same folder opens a numbered batch-rename preview. See the README for preflight checks, no-overwrite and partial-result limitations.

**Calculate size…** (context menu or Organize, Ctrl+Shift+I) scans selected files and folders on a cancellable worker; see the README for its limits, link handling and partial-result caveats.
