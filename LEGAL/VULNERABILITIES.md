# Vulnerability monitoring

**ACTION REQUIRED.** No authoritative vulnerability scan or clean bill of health is asserted. The project lockfile has no external Cargo crates, but Rust std/compiler, system libraries and Windows CRT remain relevant. Monitor Rust security advisories, GitHub Advisory Database/OSV, OS distribution security updates, GTK/libarchive and Microsoft's servicing guidance for the exact shipped or dynamically loaded versions. Record source, target, affected version, severity, exploitability, owner, remediation and date for each finding; rebuild and test artifacts when needed. `cargo audit` alone cannot cover system libraries, compiler runtimes, FFI or local code. Network-dependent advisory checks require a trusted current database and review of false positives and misses.
