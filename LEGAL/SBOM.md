# SBOM scope

**IMPLEMENTED / ACTION REQUIRED.** `SBOM.spdx.json` is an SPDX 2.3 source-workspace inventory of the two Cargo.lock workspace packages at 0.1.0, the vendored regex-lite crate, the vendored 7-Zip source archive and four platform-specific PDFium wheel artifacts. It is not a binary SBOM, not an assertion of verified copyright ownership, and uses `NOASSERTION` for unverified facts. No file-level analysis was performed. The release tag version is distinct from Cargo package versions. System libraries, compiler, standard library transitive code, static CRT, build tools and target-specific binaries are outside its scope, not declared absent.

For each release, retain actual compiler and SDK versions, lockfiles, target triple, dependency/build output, binary hashes and SBOM, then identify licenses/attributions for statically included objects and actual bundled dependencies. Validate SPDX and compare against artifacts. Review [THIRD_PARTY.md](THIRD_PARTY.md). A source SBOM cannot establish binary completeness or absence of vulnerabilities.
