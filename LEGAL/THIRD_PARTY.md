## Bundled archive engine

Release build scripts compile the standalone [7-Zip](https://github.com/ip7z/7zip) console engine by Igor Pavlov, from unmodified upstream commit `d3296e39e1f1f92c7b41c0c3848e65640428d42d`. The executable is renamed `zfm-archive-engine`; it remains 7-Zip software. Windows setup embeds the engine and corresponding source archive; Debian packages install both. Exact upstream notices, LGPL text and unRAR terms are included in `LICENSES/7zip` and shipped with packages. The Linux archive manager uses system libarchive for its normal listing, extraction and creation, and offers separate bundled-engine listing and testing. Windows uses the bundled engine for read-only listing and testing; this is not full 7-Zip UI integration. Development builds without an engine retain limited TAR inspection.

The upstream license identifies LGPL-2.1-or-later as the default, BSD-licensed and public-domain components, and RAR decoder files subject to an additional unRAR restriction. The unRAR code must not be used to develop a RAR-compatible compression algorithm. Review the notices and sources for full terms. **ACTION REQUIRED:** validate release artifacts, toolchain/runtime redistribution terms, component-level inventory, source/relinking obligations and trademark use before distribution. This note is not legal clearance.

## Bundled PDF rendering

PDF pages are rendered by PDFium from the prebuilt pypdfium2 5.15.2 wheel for each architecture. Wheel SHA-256 values and extraction are pinned in `scripts/prepare-pdfium.py`; upstream wheel license texts are copied byte-for-byte into the installed notices file. The wheel reports PDFium build 8149 but no upstream commit hash. **ACTION REQUIRED:** review the build provenance, actual linked dependencies, their licenses and vulnerability updates per release. Rendering is not sandboxed. Office rendering is not included.
