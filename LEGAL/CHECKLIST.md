# Owner release checklist

- [ ] ACTION REQUIRED — Identify actual operator, capacity, rights holders and authorizations; retain provenance evidence.
- [ ] ACTION REQUIRED — Trace compiler/std and CRT per release target; verify license/notice delivery and release-specific binary SBOM.
- [ ] ACTION REQUIRED — Enable and test private security reporting; document response ownership.
- [ ] NEEDS REVIEW — Clear names/assets in relevant markets and verify applicable registrations; don't imply a registered mark.
- [ ] NEEDS REVIEW — Review privacy, consumer terms, tax and Pakistan/international obligations with qualified counsel.
- [ ] ACTION REQUIRED — Test exact 32/64-bit artifacts on supported platforms, including legacy systems before claiming support; back up test data.
- [ ] ACTION REQUIRED — Verify packaging, license bytes, distribution signatures and hashes, release source/tag, reproducibility inputs and signing key custody.
- [ ] ACTION REQUIRED — Review advisories for shipped and runtime components; document residual risks and responsible approvals. Preserve evidence; no box is checked by this audit alone.
